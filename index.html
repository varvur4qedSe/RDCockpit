Der PDF-Bericht enthält Patientennamen, Transportdaten, Notizen und das komplette Einsatztagebuch. Das PDF wird direkt in der App erzeugt; auf iPad/iPhone danach über das Teilen-Menü „In Dateien sichern“ oder „Drucken“ wählen.

Einsatzarchiv

Vergangene Einsätze lokal sichern und später wieder öffnen.

Archivierte Einsätze öffnen standardmäßig schreibgeschützt. Über „Bearbeitung aktivieren“ kann ein archivierter Einsatz gezielt ergänzt werden. Das Archiv liegt nur in diesem Browser auf diesem Gerät.
